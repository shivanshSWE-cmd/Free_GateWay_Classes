Developer REST API Documentation

High-performance backend API powering Gateway Classes & MultiAtoms AKTU B.Tech notes store. Features sub-millisecond responses, global search indexing, and automatic streaming PDF cache.

Searchable Entities: 3,615 PYQ Question Papers: 1,961 Status: Online

Core Endpoints

GET /api/health

Returns service health status, server uptime, and entity count stats.

curl http://localhost:3000/api/health 

    


    
    

      

        GET
        /api/search?q={query}&category={cat}&limit={n}
      

      
Global fuzzy instant search across all 3,600+ subjects, units, notes, video lectures, and PYQ papers.

      

        curl "http://localhost:3000/api/search?q=machine+learning&limit=3"
        
      

      

    


    
    

      

        GET
        /api/notes/:category
      

      
Fetch structured subjects, units, DPPs, and note links for any year. Valid categories: 1year, 2ndyear, 3year, 4year, multiatom, 3year-multiatom, 4year-multiatom.

      

        curl http://localhost:3000/api/notes/1year
        
      

      

    


    
    

      

        GET
        /api/pyq?sem={sem}&code={code}&search={query}&limit={n}
      

      
Query and filter the entire database of 1,961+ official AKTU university previous year papers by semester (1 to 8), subject code, or keyword.

      

        curl "http://localhost:3000/api/pyq?sem=1&limit=2"
        
      

      

    


    
    

      

        GET
        /pyq-download/:id/:nonce?code={code}&title={title}&dl=1
      

      
Direct PDF streaming proxy with disk caching. Automatically downloads, caches in server/cache/pdfs/, and streams the official question paper PDF.

      

        http://localhost:3000/pyq-download/18692/fa1ad34acd?code=BAS101&title=Engineering_Physics
        Open PDF
